# Sąd Rejonowy w Trzciance, Wyrok, 2018-03-29, I C 114/18

## Teza

Nie można się powołać na siłę wyższą jako okoliczność wyłączającą odpowiedzialność, jeżeli skutkom działania siły wyższej można było zapobiec lub je ograniczyć.
