# Sąd Rejonowy w Trzciance, Wyrok, 2017-07-06, I C 703/16

## Teza

Poszkodowany, który żąda przywrócenia stanu poprzedniego pojazdu, nawet jeżeli otrzymuje odszkodowanie, które pokrywa koszty naprawy i nowych części, z  reguły nie tylko nie zyskuje, ale biorąc pod uwagę wartość pojazdu jako całości, gdyby chciał go sprzedać może ponieść stratę.
